# Cairo fonts for report PDFs

- Files: `Cairo-Regular.ttf` and `Cairo-Bold.ttf`.
- Font family: Cairo (Arabic and Latin).
- Source: [Cairo font files in pdfmake-rtl](https://github.com/aysnet1/pdfmake-rtl/tree/master/fonts/Cairo), vendored as unmodified font binaries.
- Original authors and license: [Cairo Project / SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/cairo/OFL.txt).
- Usage: embedded in Flutter's asset bundle and loaded from `rootBundle`; no runtime network downloads.

The accompanying `OFL.txt` retains the copyright notice and license. Do not modify the font binaries or drop the notice without another license review.
